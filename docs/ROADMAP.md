# Roadmap

## v1 — family use
- [ ] Accounts: login with 2FA (TOTP), invite-only registration
- [ ] Rent payments through Stripe, with records and receipts
- [ ] Leases with PDF upload and storage
- [ ] Roommate / split-rent support
- [ ] Deployment: Docker Compose, Cloudflare Tunnel, Tailscale admin access
- [ ] Automated off-machine backups (database + uploaded files)
- [ ] More features, to be decided

## Later — other landlords
- [ ] Subscription tiers and billing
- [ ] Admin scope isolation between landlords
- [ ] Uptime hardening (UPS, monitoring, possibly cloud failover)
